# HDX Frontend [Role C]

Interactive React + Cytoscape.js dashboard for **Hidden Dependency X-Ray**.

## Features
- **Visual Dependency Graph**: Cytoscape.js canvas showing declared vs observed nodes, vendor passports, and blast-radii.
- **Discrepancy Inspector**: Highlights undocumented endpoints observed in runtime traffic.
- **Failure Simulator**: One-click outage simulation with interactive financial exposure metrics.
- **Trust Badge**: Cryptographic Ed25519 and Solana Devnet verification status.

## Development
```bash
npm install
npm run dev
```
Runs at [http://localhost:5173](http://localhost:5173).
